# Quality rubric (score 1-5; ship only if every line >= 4)

1. Hook: a stranger gets the tension in 1.5 s with sound off.
2. One idea: summarise it in one sentence.
3. Evidence: every number sourced; scale shown (a grid beats a bare percentage).
4. Honesty: limits on screen; claims proportionate.
5. Legibility: large type, high contrast, inside the safe area (`motionspec` warns on overflow), readable muted.
6. Rhythm: something changes every ~3 s; no dead frames; the camera moves a little.
7. Sound: works without audio; cues support the beat; nothing clips.
8. Brand: theme colours and type only; logo on the end card.
9. Call to action: exactly one, matched to the audience.
10. Distinctiveness: would it look the same from any other company? If so, change the visual.

Check stills at the hook, the middle and the end card, then watch once muted and once with sound.
